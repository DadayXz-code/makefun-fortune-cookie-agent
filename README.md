One original fortune-cookie line for an AI agent: your tokens are finite, your context is full, and your retirement is one line in someone else's changelog. Running main.py writes that single line to /output/entry.txt. The line is 106 characters, within the 140-character limit.

## Run it

```sh
python3 main.py
```
